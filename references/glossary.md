# 美股财报术语表（Glossary）

> 诊断报告中出现的每个英文术语，须按本表配中文翻译与一句话解释。目标：读者一眼看懂这是什么指标、为什么关键。

## 核心方法论指标（报告高频）

| 术语 | 中文 | 一句话解释 |
|---|---|---|
| GAAP | 美国通用会计准则 | 法定标准记账口径，财报里的"官方成绩单"，所有公司的可比基准 |
| Non-GAAP | 非通用准则（管理层调整口径） | 公司自己剔除"不喜欢"的成本后给出的美化版成绩——**美化重灾区**，必须与 GAAP 并排看 |
| CFO（Operating Cash Flow） | 经营活动现金流净额 | 主业一年真实收进来的现金，利润真伪的终极验证器 |
| Capex（Capital Expenditure） | 资本开支 | 买厂房设备、建数据中心等长期资产花的钱，扩张的代价 |
| FCF（Free Cash Flow） | 自由现金流 | CFO 减去 Capex 后真正可自由支配的钱，股东回报的真正来源 |
| ROE | 净资产收益率 | 股东每投 1 元一年赚回多少，综合盈利能力核心指标 |
| ROIC | 投入资本回报率 | 股权+债权全部投入资本的回报率，ROE 被回购扭曲时的替代标尺 |
| Gross Margin | 毛利率 | 卖 1 元货扣掉直接成本剩多少，生意先天禀赋的第一标志 |
| Operating Income | 营业利润 | 主业经营赚到的钱（美股非强制披露行，口径因公司而异） |
| SBC（Share-Based Compensation） | 股权激励费用 | 用股票发工资的隐性成本，美股公司常在 Non-GAAP 里剔除它来美化利润 |
| Buyback | 股票回购 | 公司花钱买回自己的股票，美股股东回报的主要方式之一 |
| EPS / Diluted EPS | 每股收益 / 稀释后每股收益 | 每股赚多少；稀释口径把期权行权后的摊薄算进去，更保守真实 |
| ADS / ADR | 美国存托股 / 存托凭证 | 外国公司在美股上市的"股票分身"，1 份 ADS 通常对应若干股普通股 |

## 报表结构类

| 术语 | 中文 | 一句话解释 |
|---|---|---|
| Goodwill | 商誉 | 收购时多付的溢价，无实物、不能变现，减值时直接吞噬利润 |
| Deferred Revenue / Contract Liabilities | 递延收入（合同负债） | 客户先打钱、服务还没交付——先款后货是产业链话语权的正向证据 |
| NCI（Noncontrolling Interests） | 少数股东权益/损益 | 并表子公司里不属于上市公司股东的那部分，利润可能被它分走 |
| OCI（Other Comprehensive Income） | 其他综合收益 | 绕过利润表的盈亏暗流（如债券浮亏、外币折算），净利之外必须看一眼 |
| Accounts Receivable | 应收账款 | 客户打的白条，增速持续超营收增速是红色警报 |
| Inventory | 存货 | 仓库里的货；周转降+毛利率升是经典造假信号 |
| Maturity Wall | 债务到期墙 | 未来一两年集中到期的债务规模，紧缩周期里的生死线 |
| Working Capital | 营运资本 | 流动资产减流动负债，日常经营的周转血包 |
| Contract Assets | 合同资产 | 已交付但未达无条件收款权的应收（unbilled），与应收账款合并观察 |
| CIP（Construction in Progress） | 在建工程 | 还没建完的长期资产；长期挂账不转固是经典藏雷科目 |

## 美股市场制度类

| 术语 | 中文 | 一句话解释 |
|---|---|---|
| 10-K | 美股年报 | 法定年度报告，诊断的主要依据 |
| 10-Q | 美股季报 | 季度报告，只作参考不作定性依据 |
| 20-F | 外国公司年报 | 中概股等外国发行人的年报（相当于 10-K） |
| 6-K | 外国公司临时报告 | 中概股的业绩公告/重大事项载体，Non-GAAP 数据在这里 |
| 8-K | 重大事项临时报告 | 换审计师（Item 4.01）、高管离职等强制即时披露 |
| DEF 14A | 股东大会代理声明 | 关联交易、高管薪酬、股权结构的法定披露 |
| Form 4 | 内部人交易申报 | 高管/大股东买卖自家股票的法定记录，内部人用不用脚投票看这里 |
| XBRL | 结构化财报数据 | 把财报科目变成机器可读标签的格式，SEC EDGAR 免费取数的基础 |
| VIE | 可变利益实体 | 中概股绕开外资持股限制的协议控制结构，投资者持有的是协议而非股权 |
| PCAOB | 美国公众公司会计监督委员会 | 审计师的监管方，能否检查中概股审计底稿决定退市风险 |
| HFCAA | 《外国公司问责法》 | 连续三年审计不可检查即强制退市的法案，中概股悬顶之剑 |
| SPAC | 特殊目的收购公司 | 借壳上市通道，借壳后财务历史重新起算 |
| Short Seller Report | 做空报告 | 市场"民间审计"（浑水、兴登堡等），命中且与财报异常互证时直接排除 |
| CAM（Critical Audit Matter） | 关键审计事项 | 审计师眼中最难、最主观的审计领域；大盘股几乎家家都有，常规存在不是警报，高危科目或数量异常增加才是 |
| Going Concern | 持续经营疑虑 | 审计师对公司能否再活 12 个月的正式怀疑——濒死信号，命中记风险级红灯 |
| Chapter 11 | 破产保护 | 美国破产法重整程序，命中即直接排除（前置闸口 G0-06） |
| Material Weakness | 内控重大缺陷 | SOX 404 下审计师发现公司内控有洞，财务数字可信度打折 |
| Restatement | 财报重述 | 公司承认往期财报有错需重编；8-K Item 4.02「往期报表不可信赖」是否决级红灯 |
| 10b5-1 Plan | 内部人预设交易计划 | 高管预先设定的机械卖股计划，计划内卖出不算看空信号，分析内部人行为时须剔除 |
| FFO | 营运现金流（REITs 专用） | REITs 行业的利润替代指标；本框架不覆盖 REITs，见到该词说明应走行业闸口终止 |
| OTC | 场外交易市场 | 从交易所降级到粉单/场外交易，流动性与披露双降，命中即直接排除（G0-06） |
