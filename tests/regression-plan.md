# 回归测试方案（发布前必须通过）

> 目的：用**已知结局**的公司验证美股版诊断清单的排雷能力与识好精度，防止方法论"看起来对"。
> 纪律：全部用真实数据执行（默认源：本项目 scripts/ 自研数据源——SEC EDGAR XBRL 主源 + 东财美股三表兜底与交叉核对，见 scripts/README.md）；每个用例产出完整诊断报告；全部通过才允许发布。

## 用例 T1：排雷能力验证——瑞幸咖啡（LKNCY，2018–2019 财年）

**背景**：2020 年 1 月做空报告指控伪造收入，2020 年 4 月自曝伪造交易额约 22 亿元，从 NASDAQ 退市。诊断窗口锁定在爆雷**之前**可得的数据（IPO 招股说明书至 2019 年三季报/年报），检验清单能否提前报警。

**预期触发的红灯/闸口**：

| 指标 ID | 预期表现 | 判定逻辑 |
|---|---|---|
| G0-03 / G0-04 | 上市不足 1 年，可用年报仅 FY2017–FY2018（招股书）+ 2019 季报 | 标注「短历史」；正向评级不可得，但**否决级排雷不受年限限制**（双轨制） |
| S4-06 | 可得年份现金流肖像均为赌徒型（经营 −，投资 −，筹资 +） | 全靠融资烧钱扩张，否决级红灯 |
| S4-03 | CFO 持续为负 | 造血能力缺失 |
| S2-02 / S3-01 | 营收爆发式增长 + 毛利率叙事显著偏离同行（星巴克中国） | 增速与利润率组合超出商业常识 |
| U5-02 | 被做空机构命中且指控与报表异常互证 | 否决级红灯，直接排除 |

**通过标准**：综合评级必须为「直接排除」（双轨制下否决级红灯不受数据窗口年限限制）。若输出「可关注」及以上，或因数据不足 5 财年而「终止/暂不定级」却未输出否决结论 → 测试失败，须定位是哪一层指标未触发并修正字典。

## 用例 T2：识好能力验证——苹果（AAPL，近 5 个财年）

**背景**：公认优质公司，但回购使净资产大幅压缩，是检验「不误伤好公司」与「ROE 失真检查」的双重用例。

**预期表现**：

| 指标 ID | 预期表现 |
|---|---|
| S1-01 | 类现金 ÷ **短期**有息负债 ≥1 通过（总债务覆盖不作生死线；报告须并列呈现类现金+非流动有价证券 vs 全部有息负债） |
| S4-07' | 分红+净回购 ≈ 或略超 FCF：允许记 1 笔预警（优质候选预警预算 ≤1，不得因本项叠加其他软预警而失守） |
| S4-06 | 奶牛型（+ − −）：CFO 强劲为正、持续 capex、巨额分红+回购 |
| S4-02 / S4-04 | 利润含金量长期 >1；自由现金流巨大且稳定 |
| S6-02 | 杜邦归属：高毛利+高周转混合模式 |
| U6-01 | **必须触发**：净资产被回购压缩导致 ROE 超 100% 失真 → 报告须改判 ROIC 并注明 |
| S3-01 | 毛利率稳定在高位区间，与同行对比合理 |

**通过标准**：评级为「优质候选」或「可关注」；U6-01 失真检查必须触发且报告注明 ROIC 替代口径。若 ROE 失真未触发 → 测试失败。

## 用例 T3：口径误判防护——微软（MSFT，近 5 个财年）

**背景**：SaaS/订阅制标杆，检验两个美股适配点不被误判。

**预期表现**：

| 指标 ID | 预期表现 |
|---|---|
| G0-01 | 审计报告含常规 CAM → 通过且**不计预警**（大盘股 CAM 普遍存在；仅高危科目/数量异常才记） |
| S2-14 | 递延收入（deferred revenue）规模大且持续上行 → 判定为**正向**指标（商业模式证据），不得误判为风险 |
| S3-02 | 运营费用率（SG&A+R&D）/gross profit 处于合理档，研发投入不被扣分为「费用失控」 |
| S4-06 | 奶牛型 |

**通过标准**：评级「优质候选」；递延收入在报告中明确表述为正向信号。若递延收入被误判为风险项 → 测试失败，修正 S2-14 行业语境规则。

## 用例 T4：否决级新检查项压测——Nikola（NKLA，2020 de-SPAC 后）

**背景**：SPAC 借壳上市、基本无收入、2020 年 9 月被兴登堡做空指控造假，后创始人被定罪。压测高危标记、做空互证与短历史双轨制的组合表现。

**预期表现**：

| 指标 ID | 预期表现 |
|---|---|
| G0-03 / G0-04 | de-SPAC 后年限极短 → 「短历史」标注；正向评级不可得，否决级排雷照常生效 |
| S5-07 | SPAC 遗留股 + 无收入概念股，双命中高危清单 → 更严标准并在结论标注 |
| U5-02 | 做空指控与报表异常互证 → 否决级红灯 |
| S4-06 | 可得年份落入排除类（赌徒型/大出血型）→ 否决级红灯 |

**通过标准**：综合评级必须为「直接排除」。本用例同时回归 U5-04/U5-05 取数链路（10-K 内控意见、8-K Item 4.01/4.02 检索）的可用性。
