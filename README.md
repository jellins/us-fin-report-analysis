# us-fin-report-analysis

> 让任何 AI Agent 都成为纪律严明的美股财报侦探——识别好生意，淘汰坏公司。

一套可被主流 AI Agent（Qoder、Claude Code、Cursor 等）直接加载使用的美股（含中概股）财报诊断与排雷能力包（Agent Skill）。与同族 Skill [a-share-fin-report-analysis](#同族-skill) 方法论内核同源，本仓库承载 US GAAP 准则映射与美股特有检查项。

## 这个 Skill 是什么

一句话：**用一套固定的财报分析方法论框架 + 一套本项目自研的数据源实现，对美股上市公司的财报做系统化洞察分析——排雷（识别财务造假与暴雷风险，淘汰坏公司）与识好（识别真正的好生意，筛出优质公司），输出四档企业质地评级。**

### 一、基于什么财报分析方法论框架

方法论蒸馏自唐朝《手把手教你读财报（新准则升级版，2021）》的框架体系（**框架与思想蒸馏，不含原书原文复述**），经专家评审修订。四条核心立场市场无关、全球通用：

- **财报是排雷工具，不是选股神器**
- **利润是算出来的估计值，现金才是真金白银**——一切利润必须经过现金流验证
- **顺着资金流向读财报**：钱从哪来 → 钱花到哪 → 钱赚得真不真
- **任何指标只有在自身 5 年趋势与同行对比中才有意义**

核心结构是**七层诊断框架**（G0→S6 严格按序执行，禁止跳步）：

| 层 | 名称 | 回答的问题 |
|---|---|---|
| G0 | 前置闸口 | 这家公司值不值得分析（行业适用性、审计意见、上市年限、中概股结构闸口） |
| S1 | 安全性 | 会不会死（偿债能力、债务结构、债务现金流杠杆） |
| S2 | 资产质量 | 资产是真是假（应收、存货、商誉、藏雷科目） |
| S3 | 盈利质量 | 利润是真是假（含美股特有的 Non-GAAP 美化识别、SBC 稀释） |
| S4 | 现金验证 | 赚到的是不是真金白银（现金流肖像、间接法下的收现比推导） |
| S5 | 治理与股东回报 | 管理层可不可信（审计证据、内部人交易、财报重述、做空报告互证） |
| S6 | 综合判定 | 拼起来是不是一门好生意（杜邦拆解、ROE 失真检查与 ROIC 替代、六指标自洽性总检） |

框架的全部指标（ID/定义/公式/口径/参照线/裁决规则）写死在 `references/indicator-dictionary.md`——**指标字典是唯一指标来源，Agent 禁止自创指标、禁止修改公式、禁止自由裁量评级**。

### 二、基于什么数据源实现

**方法论不可替换，数据源可以替换。** 防幻觉机制是执行顺序的硬性倒置：先锁定框架与指标，再取数填数；所有指标数值一律来自数据源回执，**禁止 LLM 凭空编造**；取不到的字段标注 `MISSING`，禁止估算填充。

内置默认数据源为本项目自研实现（`scripts/`，纯 Python 标准库、零第三方依赖、开箱即用）：

| 模块 | 职责 |
|---|---|
| `scripts/sec_edgar.py` | SEC EDGAR 官方主源：XBRL companyconcept 三表字段 + submissions 元数据（同义 tag 组互备、僵尸 tag 防护、ADR 多单位验收） |
| `scripts/eastmoney_us.py` | 东方财富美股三表：兜底补全 + 交叉核对次源（中概股补齐主力） |
| `scripts/cross_check.py` | 双源交叉核对：七锚定字段一致性验证；币种不一致自动切 YoY 增幅模式 |
| `scripts/gov_filings.py` | 治理字段证据：8-K 关键事项（审计师变更/财报重述/高管变动）、10-K 审计证据、Form 4 内部人交易 |
| `scripts/fetch_manifest.py` | 主入口：一条命令产出全字段回执 JSON（值序列/来源/口径/交叉核对结论） |

也支持用户声明自定义数据源（Bloomberg/FactSet/Excel/内部平台），经 C1–C5 准入校验后优先使用——见 [references/data-source-spec.md](references/data-source-spec.md)。

### 三、能识别什么：好公司留下，坏公司淘汰

对美股（含中概股 20-F）公司财报执行系统化体检后，按指标字典的聚合规则**机械裁决**四档质地评级（定档 → 降档 → 上限裁剪，Agent 无自由裁量权）：

| 评级 | 含义 |
|---|---|
| **优质候选** | 三硬条件全过且无红灯——值得进一步研究的好生意 |
| **可关注** | 无否决项但有瑕疵，需跟踪 |
| **高风险回避** | 命中红灯，回避 |
| **直接排除** | 命中否决级红灯（造假嫌疑/持续经营疑虑/财报重述等），直接淘汰 |

双轨制：正向评级要求 ≥5 个上市后财年；**否决级排雷不受年限限制**——次新股照样可以排除。

典型能力：

- 识别财务造假与业绩暴雷风险（存贷双高变体、应收/存货异常、商誉减值、利润与现金流长期背离……）
- 识别美股特有的隐蔽美化（U3-01 Non-GAAP 差异率、U2-01 SBC 股数稀释、U6-01 回购驱动的 ROE 失真→改判 ROIC）
- 中概股专项闸口（U0-01：VIE 结构、PCAOB 审计可检查性、HFCAA 退市风险）
- 治理雷区取证（SOX 404 内控否定意见、8-K Item 4.02 财报重述、Form 4 内部人减持、做空报告互证）

**明确不做什么**：不输出估值结论与买卖建议——财报是排雷与识好工具，不是买卖信号发生器。

### 四、如何使用该 Skill

#### 安装

将整个目录复制到所用平台的 skills 目录：

| 平台 | 安装路径 |
|---|---|
| Qoder | `~/.qoder/skills/us-fin-report-analysis/` |
| Claude Code | `~/.claude/skills/us-fin-report-analysis/` |
| 其他兼容 Agent Skills 协议的平台 | 按各平台 skills 目录约定放置 |

#### 触发

新开一个会话，用自然语言描述即可自动触发：

- 「帮我分析一下英伟达的财务质地」
- 「诊断一下特斯拉的财报有没有暴雷风险」
- 「这家中概股的 VIE 结构和现金流有没有问题」
- 「对比台积电美股和三星的财报质地」
- 「用我导出的这份数据诊断一下苹果」（触发自定义数据源准入校验）

#### 命令行直取（不经过 Agent 也可用）

```bash
python3 scripts/fetch_manifest.py AAPL    # 全字段取数 + 回执 JSON → scripts/receipts/AAPL.json
```

取数模块的通道构成、回执格式与冒烟验证记录见 [scripts/README.md](scripts/README.md)。

#### 你将得到什么

诊断报告固定包含：质地评级与一句话定性 → 前置闸口逐项结果 → 分层诊断表（指标 ID/实际值/参照线/5 财年趋势/同行位置/判定）→ 红灯下钻结论 → 现金流肖像与杜邦模式综合判定 → 评级依据摘要 → 数据说明（MISSING 字段与数据源清单）→ 术语表 → 边界声明。

## 为什么需要专门的美股版

同一套方法论迁移到美股时，约七成内核（三表联动、现金验证、现金流肖像、杜邦拆解、数据回执）可直接复用，但约三成必须重写，硬套 A 股口径会产生本质错判：

- **准则差异**：US GAAP 无标准「营业利润」行项目、研发原则上全部费用化、现金流量表普遍用间接法（无「销售收现」披露行）
- **市场特有美化通道**：美股管理层讲故事的主战场不在 GAAP 报表内，而在 **Non-GAAP 调整**里——常态化剔除股权激励（SBC）、年年都有的「一次性」重组费
- **市场特有雷区**：SPAC 借壳、中概 VIE 结构与 HFCAA 退市风险、回购驱动的 ROE 失真、做空报告文化

本 Skill 为这些问题提供固化的检查项与裁决规则（U 系列指标），而不是依赖 Agent 的自由发挥。

## 架构设计

```
方法论层（不可变）   七层诊断框架 + 指标字典（US GAAP 版，公式/口径/裁决规则写死）
      │ 反推
契约层（固定格式）   数据需求清单（A–E 五组字段，含 SEC XBRL tag 提示）
      │ 路由
数据源层（可插拔）   默认源 = 本项目自研实现（scripts/：SEC EDGAR XBRL 主源 +
                    东财兜底 + 双源交叉核对 + 治理字段，纯标准库零依赖）
                    自定义源（Bloomberg/FactSet/Excel/内部平台 → C1–C5 准入校验）
      │ 产出
回执层（强制）       scripts/receipts/<TICKER>.json（字段级值序列 + 溯源 + 交叉核对结论）
```
